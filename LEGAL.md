# Legal / copyright

## What this mod is

Dracula UI is a **non-commercial fan mod** for Stardew Valley. It follows the same **technical pattern** as established UI recolors (e.g. sqbr's [Stardew-Valley-Mod-Tools](https://github.com/sqbr/Stardew-Valley-Mod-Tools), Starry Blue UI): a generator reads sprites from **your purchased copy** of the game and writes recolored files **locally**.

## What we do not redistribute

- Vanilla Stardew Valley sprites (© ConcernedApe)
- Recolored PNGs derived from those sprites

Those files are **gitignored** and must not be uploaded to GitHub, Nexus, Discord, etc.

## What we do distribute

- Content Patcher / Theme Manager configuration (JSON)
- Dracula palette definitions (MIT, [Dracula Theme](https://draculatheme.com))
- Python/PowerShell tooling that runs on **your** machine
- Original documentation and patch definitions

## Comparison with typical Nexus UI mods

| | Typical Nexus UI recolor ZIP | Dracula UI |
|--|------------------------------|------------|
| PNGs in download | Yes (recolored vanilla) | **No** |
| User must own the game | Yes | Yes |
| Setup step | Extract to Mods | Extract + **run setup once** |
| Fan / non-commercial | Usually | Yes |

Many Nexus UI mods operate in a **community gray zone** by shipping recolored derivatives. This project avoids **redistributing** those derivatives while offering a similar in-game result.

## Your responsibilities

1. Purchase Stardew Valley legitimately.
2. Run setup only against **your** install.
3. Do not share generated PNGs publicly.

## Original contributions

If you contribute **original** pixel art (not traced from vanilla), you may license it for inclusion in this repository explicitly in your pull request.
